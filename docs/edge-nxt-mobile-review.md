# EDGE NXT — 모바일 화면·PWA 아이콘 점검

기준 브랜치: `edge-nxt-step1-20261025`
기준 커밋: `1ee7a760d2f4412a3f287bf8632ec548b1c84f06`

## 변경 내용

- NXT 화면의 고정된 “애프터마켓” 표기를 “NXT MARKET DATA”로 바꿔 세션을 확인하지 않은 상태에서 장 구분을 단정하지 않도록 했다.
- 모바일에서 NXT TOP10과 뉴스·공시 탭을 화면 상단에 유지하고 상태·안내 문구를 읽기 쉽게 조정했다.
- EDGE NXT용 192px, 512px, maskable 512px 아이콘을 분리했다. 매니페스트는 `standalone` 표시 모드를 사용한다.
- 서비스 워커 캐시 이름과 정적 스크립트 URL을 갱신해 기존 EDGE NEWS 화면 캐시를 교체하도록 했다. 상태 JSON은 배포 산출물에서 선택적으로 빠질 수 있으므로 셸 선캐시 필수 항목에서 제외해 파일 부재가 서비스 워커 설치를 막지 않게 했다.
- 사이트 설치 버튼은 브라우저 설치 요청을 호출하지 않고 기존 홈 화면 안내만 연다.

## 회색 아이콘 배지

사이트 코드만으로 Android 런처가 브라우저 바로가기 아이콘에 붙이는 출처 배지를 제거할 수는 없다. `maskable` 아이콘은 OS가 아이콘 모양을 자를 때 로고가 잘리지 않도록 하는 용도이며 브라우저 출처 배지를 끄는 설정은 아니다. Android 홈 화면에서 PWA가 앱처럼 독립 실행되는지는 브라우저의 PWA 설치 흐름, manifest, 서비스 워커 지원에 달려 있다. 지금은 자동 설치 프롬프트를 쓰지 않으며, 삼성 인터넷의 홈 화면 안내를 유지한다.

회색 배지의 정확한 발생 주체는 대상 갤럭시의 OS·런처·삼성 인터넷 버전과 추가된 방식이 확인되기 전까지 확정하지 않는다. 실기기 설치 결과도 아직 검증하지 않았다.

## 검증 제한

- 정적 UI·manifest 검사: 통과
- 실제 KIS 데이터: 없음. TOP10은 연결 대기 상태여야 한다.
- Android 홈 화면 추가 및 주소창 없는 실행: 실기기 검증 전
- 별도 테스트 URL: 별도 Render workspace 선택과 서비스 생성 이후 제공
- 정식 운영 `main` 및 기존 GitHub Pages에는 배포하지 않았다.
