## 문의 경로

- API 가이드·FAQ·Chatbot: https://apiportal.koreainvestment.com/
- KIS Open API 이용 안내: https://apiportal.koreainvestment.com/about-howto
- 제휴 안내 및 제출 조건: https://apiportal.koreainvestment.com/provider-apply
- 공개 샘플: https://github.com/koreainvestment/open-trading-api

KIS 개발자센터는 개발 질문에 FAQ·Chatbot을 안내하고 시스템 장애는 고객의 소리(VOC)로 접수하도록 안내합니다. 고객의 소리의 로그인 요건은 이번 조사에서 확인하지 않았습니다. `openapi@koreainvestment.com`은 제휴 제안 안내에 공개된 주소이며 일반 기술지원 주소라고 단정하지 않습니다. STEP 67 문의서 중 기술 질문은 먼저 공개 FAQ/Chatbot 또는 API 가이드 문의 경로로 확인하고, 담당자가 지정한 공식 채널로 제출할 수 있도록 작성했습니다.

## 제출 문안

**제목: NXT 실시간 체결 H0NXCNT0 및 NXT 등락률 순위 API 상세 계약 확인 요청**

안녕하세요. EDGE NXT 개발 준비를 위해 KIS Open API의 NXT 시세 계약을 검토하고 있습니다. 현재 실제 인증 API 호출이나 수신 데이터 저장·공개는 진행하지 않았습니다. 공개 샘플에서 확인되지 않는 최신 공식 명세와 적용 범위를 확인하고 싶습니다.

### P0 — 실제 시세 수신과 해석에 필요한 계약

1. `H0NXCNT0`의 현재 공식 계약 버전·시행일과 전체 응답 명세를 제공해 주실 수 있습니까? 공개 예제의 출력 컬럼은 47개로 확인했으나 실제 wire schema는 확인하지 못했습니다. 필드별 wire type, 길이, nullable/빈 값, 부호, 값 범위, 단위, 오류·재전송 규칙이 포함된 문서를 요청드립니다.
2. 다음 필드의 정확한 의미와 단위를 확인해 주십시오.
   - `STCK_PRPR`: 가격 표현 단위 및 호가단위 적용 방식
   - `PRDY_CTRT`: 비교 기준가격·기준 시점, 부호, 배율, 반올림 규칙
   - `ACML_TR_PBMN`: 통화 및 거래대금 단위, 누적 산정 방식
   - `ACML_VOL`: 일별·세션별 누적 범위와 PRE/정규장/AFTER 전환 시 리셋 여부
   - `CNTG_VOL`: 단일 체결량인지 기타 집계값인지
3. `BSOP_DATE` 및 `STCK_CNTG_HOUR`의 정확한 형식, 기준 시간대, 거래일 경계 규칙을 알려 주십시오. 체결시각과 서버 원천 생성시각, 클라이언트 수신시각이 각각 제공되는지도 확인 부탁드립니다.
4. H0NXCNT0 응답에 지연 여부를 나타내는 명시적 필드가 있는지, 또는 해당 TR의 실시간/지연 제공 등급과 지연 허용 기준이 별도 계약에 정의돼 있는지 확인 부탁드립니다.
5. `MARKET_CLS_CODE` 1(PRE), 2(정규장), 3(AFTER), 5(종가) 해석이 H0NXCNT0에만 적용되는지, 코드별 세션 적용 범위 및 예외를 확인해 주십시오.

### P1 — NXT PRE·AFTER 상승률 TOP10 정확도

6. REST 경로 `/uapi/domestic-stock/v1/ranking/fluctuation`에서 `fid_cond_mrkt_div_code=NX`를 사용할 경우 PRE, 정규장, AFTER를 따로 선택하거나 식별할 수 있습니까? 세션별 순위가 가능하다면 적용 파라미터와 세션별 기준가격을 알려 주십시오.
7. 반환 건수의 기본값·최댓값, `fid_input_cnt_1=0`의 정확한 의미, `tr_cont` 연속조회 조건과 마지막 페이지 판정 방법을 확인 부탁드립니다. 전체 NXT 거래대상 종목이 누락 없이 포함되는 계약인지도 알려 주십시오.
8. 공개 MCP 설정과 예제 호출에서 정렬 코드가 각각 `0000` 및 `0`으로 표기돼 있습니다. 현재 유효한 파라미터 값과 NXT 적용 시 정렬 순서를 확인해 주십시오.
9. 이 순위 API가 제공하는 데이터의 지연 등급, 호출 제한 및 개인 API 계정별 사용 권한을 확인 부탁드립니다. 세션별 전체 TOP10 산출을 위해 KIS가 권장하는 공식 데이터 조합이 있다면 문서와 함께 안내 부탁드립니다.

### P2 — 공식 종목 마스터

10. 개발자센터의 KOSPI(NXT)·KOSDAQ(NXT) `.mst` 다운로드 항목은 어떤 종목 범위와 기준일을 나타냅니까? 공식 다운로드 경로, 갱신 주기, 전체성 보장 여부, NXT 거래대상과 KIS 조회 가능 종목의 차이, PRE·AFTER별 자격 필드 및 변경 이력 제공 여부를 확인 부탁드립니다.

답변 시 공개 가능한 최신 상세 API 문서, 필드 정의서, 파라미터 표, 종목 마스터 파일 안내와 적용일을 보내 주시면 감사하겠습니다. 계정별 권한이 필요한 내용은 일반 정책과 별도로 구분해 주십시오.

감사합니다.

## 질문별 이유와 현재 증거

현재 공개 KIS 자료는 H0NXCNT0 예제의 컬럼 식별자·순서와 NXT 선택 가능한 순위 경로 일부를 보여 줍니다. 실 응답, 단위, PRE·AFTER 분리, 호출 한도, 계정별 권한은 확인되지 않았습니다. 공개 문서 URL과 적용 범위는 `docs/nxt-official-contract-audit.md`에 정리돼 있습니다.
