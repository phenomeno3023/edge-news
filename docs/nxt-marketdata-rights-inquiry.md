# NXT 시세 이용권한 문의서

작성일: 2026-11-04  
상태: 제출용 초안, 발송하지 않음  
수신 우선 경로: NXT Data Portal 데이터 이용계약 `data@nextrade.co.kr`; 실시간·종가 배포 `mdds@nextrade.co.kr`. KIS 일반 이용조건은 API 가이드·공식 담당 경로를 통해 별도로 확인.

## 제출 문안

**제목: EDGE NXT 시세 데이터 이용 범위 및 필요한 계약 확인 요청**

안녕하세요. EDGE NXT라는 국내 주식 뉴스·공시 연계 개발 프로젝트의 시세 데이터 이용 가능 범위를 검토 중입니다. 현재 KIS/NXT 실제 시세 API 호출, 실제 데이터 공개, 계약 신청은 하지 않았습니다. 아래 각 사용 형태가 허용되는지와 필요한 계약·승인 주체를 구분해 안내 부탁드립니다.

다음은 서로 다른 사용 형태입니다. 하나의 허용 답변을 다른 항목에 확대 적용하지 말아 주십시오.

A. 개인 투자자가 본인 명의 계정·인증정보로 본인 투자 목적으로 API를 조회하는 경우  
B. 조회 결과를 개인 소유 휴대전화·PC 등 본인 장치에만 표시하는 경우  
C. 인증된 개인만 접속하는 비공개 웹앱에 표시하고 서버에 제한적으로 저장하는 경우  
D. 불특정 다수 또는 로그인한 다른 사용자가 접근할 수 있는 공개 웹앱에 표시하는 경우  
E. 실시간 시세를 웹·API·JSON·앱으로 제3자에게 제공하거나 재배포하는 경우  
F. 지연 시세·종가 데이터도 같은 방식으로 제공하는 경우

각 항목에 대해 다음 내용을 확인 부탁드립니다.

1. 신청 가능한 개인·법인 유형과 신청 주체의 요건
2. KIS Open API 계정 권한과 별도로 필요한 NXT·KRX·코스콤 정보이용계약
3. 내부 표시, 다중 사용자 표시, 외부 공개, API/JSON 제공, 저장 및 재배포별 계약 구분
4. 실시간과 지연·종가 데이터의 조건·요금·보관기간·출처 표시 규칙
5. 서비스 이용자 수·접속 범위·웹 호스팅 방식에 따른 추가 승인 여부
6. 계약 상대방, 공식 신청 URL, 제출 서류, 심사 기간과 갱신·해지 조건
7. 개인용 비공개 앱으로 시작할 경우 공개 전환 시 필요한 별도 절차

KIS Developers 공개 안내에서는 개인 Open API 이용과 제휴서비스를 구분하고 있으며, 제휴 안내는 제도권 금융회사 등 자격을 제한하고 거래소 시세정보 이용계약을 언급합니다. NXT Data Portal은 데이터 이용·네트워크 계약 완료 후 시장 데이터를 이용할 수 있다고 안내합니다. 이 일반 안내가 EDGE NXT의 특정 계정·서비스 권한을 승인하는 것으로 해석되지는 않는다고 이해하고 있습니다. 맞는지 확인 부탁드립니다.

본 문의는 계약이나 신청을 진행하는 것이 아닙니다. 적용 가능한 공식 약관, 상품 사양, 신청 절차 링크를 안내해 주시면 감사하겠습니다.

감사합니다.

## 내부 사용 구분

- A~C가 허용돼도 D~F는 자동 허용되지 않습니다.
- 공개 재배포 권한과 계정별 개인 API 사용 권한을 분리해서 기록해야 합니다.
- 답변 또는 계약서가 오기 전까지 공개 시세 출력은 `BLOCKED`로 유지합니다.
