# EDGE NXT TOP10 개발 미리보기

## 실행

프로젝트 루트에서 로컬 정적 서버를 실행합니다.

```sh
python3 -m http.server 8000 --bind 127.0.0.1 --directory .
```

브라우저에서 `http://127.0.0.1:8000/preview/nxt/`를 엽니다. 페이지는 ES modules를 사용하므로 `file://`로 직접 열지 말고 HTTP 서버를 사용해야 합니다. 이 경로는 개발 미리보기 전용이며 운영 Pages에 연결되지 않습니다.

## 화면과 동작

- PRE와 AFTER 순위를 별도로 계산하고 세션 탭으로 전환합니다.
- 순위, 합성 종목명·코드, 가상 가격, 상승률, 거래량, 거래대금, 기준 시각, 출처와 지연 표시를 보여줍니다.
- 종목 카드를 누르면 해당 세션의 뉴스 후보, KIND 공시, DART 공시, 발표 시각과 시각 정밀도를 확인할 수 있습니다.
- 상세 화면에서 TOP10 목록으로 돌아올 수 있습니다.
- 모든 페이지 상태에 Mock 경고를 표시하며 테스트 종목코드 990001부터 990012까지는 합성 식별자입니다.
- 합성 기사와 공시 링크는 `example.com/mock/`을 사용합니다.

## 데이터 흐름

`mock-data.js`가 인메모리 합성 시세·뉴스·공시 데이터를 만들고 기존 `calculateTop10()`과 `enrichTop10()`을 재사용합니다. 실제 API, 저장소, 운영 JSON은 읽지 않습니다. 가상 스냅샷은 2분이 지나면 순위를 숨기고 오래된 데이터 안내를 표시합니다. 잘못된 시세와 신선도 만료 시세는 계산 엔진에서 제외되며 제외 건수를 표시합니다.

새 기사·공시 데이터는 HTML 텍스트 이스케이프를 거칩니다. 외부 링크는 HTTP(S) 주소만 허용하고 사용자 정보가 URL에 들어간 주소는 차단합니다. 링크에는 `noopener noreferrer`를 지정합니다.

## 격리 검증

```sh
node --test test/nxt-preview.test.js
npm test
```

단위 테스트는 생성된 DOM 마크업과 모바일·데스크톱 CSS 규칙을 검사합니다. 실제 브라우저가 같은 미리보기 환경에 연결되지 않는 경우 브라우저 상호작용 검증으로 간주하지 않습니다.
