# STEP 68 — 모바일 TOP10 및 뉴스·공시 연결 품질

## 기존 화면 확인

`preview/nxt/`의 기존 화면에는 PRE·AFTER 분리, 종목 상세, Provenance 표시, 읽기 전용 검토 대기열, 필터·페이지 이동, JSON 내보내기가 이미 있습니다. 공유 상태 전환은 `ui-state.js`에서 처리하며 Node 테스트가 같은 전환 함수를 사용합니다. KIND 원시 구조는 `UNVERIFIED`, DART 문서 구조는 `DOCUMENTED`, DART payload 진위는 `UNVERIFIED`, 합성 확정 매칭은 0건입니다.

## 변경 사항

- 종목 상세에 뉴스와 KIND·DART 공시를 함께 정렬하는 시간순 구역을 추가했습니다. 날짜 정밀도와 시세 시각 대비 관계를 표시하며, 정확한 시각이 없는 자료는 임의의 시간을 만들지 않습니다.
- 원문 발표, 최초 확인, 원천 관측, 수집, 시세 관측 시각을 각각 따로 표시합니다. 값이 없는 필드는 미확인으로 둡니다.
- 종전의 뉴스·KIND·DART별 섹션과 근거 상세는 유지합니다.
- 검토 대기열과 미배정 후보에 JSON 및 CSV 다운로드 버튼을 연결했습니다. 현재 화면의 검색 조건과 범위를 사용하며 최대 100건을 내보냅니다. LIVE 모드와 잘못된 항목은 기존 데이터 계약 검증에서 거부됩니다.
- 브라우저와 Node가 같은 CSV 직렬화 함수를 사용하도록 공용 계약으로 옮겼습니다. 수식 주입 방지, 인용부호·줄바꿈 처리, null 값 처리를 유지합니다.

## 표시와 안전 정책

시세는 계속 MOCK으로 표시됩니다. 뉴스·공시는 검증 전 후보이며, 시간상 먼저 발생했다는 사실만으로 상승 원인이나 호재·악재를 확정하지 않습니다. 날짜만 있는 공시는 시·분 단위 사건과 같은 정밀도로 비교하지 않습니다. 선택, 검토, 필터, 내보내기는 confidence 또는 검토 상태를 변경하지 않습니다.
