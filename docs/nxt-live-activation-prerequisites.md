# EDGE NXT 실제 시세 활성화 선행 조건

최종 갱신: 2026-11-04. 이 문서는 개발 검증 게이트를 운영 활성화와 분리한다. 각 단계는 독립된 증거와 별도 승인이 필요하다. 앞 단계 충족은 다음 단계의 자동 허가가 아니다.

| 단계 | 필요한 근거·행동 | 승인/완료 기준 | 현재 |
|---|---|---|---|
| A. 공식 계약 문서 확보 | KIS H0NXCNT0 및 ranking API 최신 상세 명세, NXT universe/세션/예외 문서 | 버전·시행일·필드·단위·요청/응답 계약 보관 | PARTIAL — 컬럼 목록/일부 parameter만 공개 예제에서 확인 |
| B. 개인 API 사용 권한 확인 | EDGE NXT 개발 주체와 이용 목적에 적용되는 KIS 계정/API 승인 | 계정 단위 권한, 호출 제한, 내부 표시 범위 확인 | UNVERIFIED — 인증/계정 상태 미조회 |
| C. 격리 실제 응답 검증 | 사용자가 별도 승인한 비운영 테스트 계정/수단으로 안전한 격리 환경에서 최소 샘플 확인 | payload 출처·진위, 원시 bytes digest, 타입·단위·시각·세션 테스트 | BLOCKED — 실제 API를 호출하지 않았고 승인된 응답이 없음 |
| D. 시장·순위 정확도 검증 | 거래대상 전체 목록, PRE/AFTER eligibility, 기준가·정렬·pagination·날짜 정책 | 서로 다른 거래일/세션을 포함한 표본 및 누락·중복·경계 테스트 통과 | BLOCKED — 목록·세션 순위 범위·calendar 결손 |
| E. 개인 내부 앱 표시 권한 | KIS와 거래소/코스콤 등 권리 주체의 적용 권한 확인 | 사용자가 통제하는 비공개 앱의 화면표시/저장 조건 문서 확보 | BLOCKED — 계정별 계약 미확인 |
| F. 외부 공개·재배포 권한 | 다중 사용자 공개 웹/Pages, 실시간·지연 데이터 권리 확인 | EDGE NXT 서비스와 배포 매체를 명시한 계약/승인 확보 | BLOCKED — 개인 Open API의 제3자 제공 제한이 안내됨 |
| G. 실제 브라우저 검증 | 격리된 실제 데이터 staging 화면, 360~1280px 및 상호작용 | 시각·지연·출처·오류·접근성 확인. 데이터 공개 권리와 분리 | UNVERIFIED — 실제 브라우저 검증은 아직 별도 수행 필요 |
| H. 운영 배포 승인 | 보안/운영 검토, rollback 계획, 별도 담당자 승인 | 명시적 운영 승인 뒤 별도 배포 절차 | BLOCKED — 이번 STEP에서 운영 배포 불가 |

## 즉시 적용 규칙

- 합성 fixture는 계속 `mock`으로 표시한다. 문서 예제도 실제 데이터/LIVE가 아니다.
- 인증된 실응답이 없으면 `payloadAuthenticity=UNVERIFIED`다.
- NXT 전체 유니버스 및 세션 적격성이 불확실하면 실제 TOP10 전체성을 표시하지 않는다.
- 공개 재배포 권한이 불확실하거나 거부된 경우 actual quote의 JSON/Pages 출력을 차단한다.
- 차단된 실데이터를 Mock으로 포장하지 않고 `blocked` 또는 `unavailable` 상태로 분리한다.
- 뉴스·공시 매칭 확정은 시세 검증과 별도 판단이다.

## 승인 분리

1. 문서 계약 확인은 개인 API 계정 권한을 주지 않는다.
2. 개인 API 호출 권한은 공개 화면 표시나 재배포 권한을 주지 않는다.
3. 테스트 응답 진위 확인은 NXT 전체시장 TOP10 완전성을 증명하지 않는다.
4. staging 검증은 운영 배포를 승인하지 않는다.
5. 운영 배포는 이번 작업의 범위 밖이며 별도 명시 승인을 필요로 한다.
